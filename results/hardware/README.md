# IBM Quantum hardware results

No completed IBM QPU measurement is archived here yet. Place only validated, non-secret result files in this directory.

For each submitted job, preserve: backend name and calibration timestamp; job ID; UTC submission/completion times; logical and ISA circuit summaries, layout and two-qubit gate count; observable and identity/nuclear-energy offset convention; shots or precision; mitigation and twirling options; energy estimate and uncertainty; ideal statevector/active-space CASCI reference; and any job warnings or truncation.

Never save API keys, account tokens, Runtime credentials, or private account metadata. A dry run and backend-calibrated Aer simulator output are not hardware measurements. This project’s QPU workflow evaluates fixed saved parameters; it does not optimize parameters on the hardware.
