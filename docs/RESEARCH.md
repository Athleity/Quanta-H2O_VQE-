# Research and design decisions

## Scope

The target is neutral, closed-shell H₂O on an **asymmetric O–H extension coordinate**. The default structure is O–H₁ = 0.96 Å, O–H₂ = 2.20 Å, H–O–H = 104.5°. The fixed angle is a declared modeling choice; the two distances by themselves do not define the geometry. This coordinate is not the harmonic asymmetric-stretch normal mode, where both bonds move in opposite directions around an equilibrium structure.

The benchmark separates three different errors:

1. **Basis-set error:** STO-3G is a minimal basis. It is selected for a compact, reproducible quantum model, not as a converged chemical prediction.
2. **Active-space error:** the VQE model freezes one doubly occupied orbital and retains CAS(8e,6o). It is tested against all-electron STO-3G FCI at every geometry.
3. **Variational/optimization error:** VQE energies are compared with exact CASCI for the same active-space Hamiltonian. These two errors are never conflated.

At the default geometry, each reference calculation is derived from molecular integrals. No Pauli coefficients, ground energies, optimizer outcomes, or noisy-shot rejection rates are hard-coded. Results should only be reported after the WSL run writes the reference and summary files.

## Why this model

H₂O/STO-3G has 10 electrons in 7 spatial orbitals, or 14 spin orbitals before reduction. The proposed “lossless” CAS(4e,4o) model would discard valence correlation beyond that selected space; symmetry tapering cannot restore omitted electronic degrees of freedom. CAS(8e,6o) freezes only the lowest doubly occupied orbital and keeps all six valence spatial orbitals. Its 12 spin orbitals are reduced further by a particle-aware parity mapping. The omitted-core effect is measurable as the all-electron-FCI minus frozen-core-CASCI difference.

This is an intentionally manageable quantum algorithm benchmark, not a claim that 10 mapped qubits reproduce the exact full-basis molecular problem. A more ambitious follow-up can run the full 14-spin-orbital Hamiltonian after the active-space results are stable; its larger UCC pool and state space make it a poor first debugging target.

## Algorithm selection

The fixed-ansatz comparison includes UCCSD and Qiskit Nature's PUCCSD, and the algorithm comparison includes fermionic ADAPT-VQE. All receive the same mapped active-space Hamiltonian and are measured against the same CASCI value. Fixed ansätze get repeated seeded starts; the first is exactly the Hartree–Fock determinant. Optimizer and budgets are exposed for SLSQP, COBYLA, and SPSA. Circuit depth, size, CNOT count, and parameter count are recorded because parameter count alone does not measure circuit cost. A generic RY/RZ hardware-efficient ansatz is excluded: it does not conserve electron number or spin, and its unpenalized energy can exploit unphysical sectors. A valid HEA baseline would need sector constraints and leakage diagnostics.

The script uses Qiskit Algorithms' ADAPT-VQE with the Qiskit Nature UCCSD excitation pool. This is **fermionic ADAPT-VQE**. It is not labeled Qubit-ADAPT or TETRIS-ADAPT. Those are valid alternative studies, but they use different operator pools and/or selection rules; calling this implementation by those names would be inaccurate. An angle-size pruning threshold is also excluded: a small current coefficient alone does not establish that deleting an excitation preserves the optimum. Any future pruning experiment should remove an operator, reoptimize, and report the resulting energy and circuit-depth changes. The observed four-cycle H₂O run (4 parameters, 8.64 mHa error, 381 s) shows that ADAPT is compact in parameters but expensive and not yet converged in this setup; it does not establish a general ranking against UCCSD.

The first pass is ideal statevector evaluation. It isolates ansatz and optimizer behavior. Finite-shot and device noise should be introduced only after the noiseless model passes the independent exact-energy check. Symmetry post-selection is a later mitigation experiment, not a promise of a fixed rejection percentage or a zero-cost filter.

## Primary literature

### Water-specific quantum-chemistry studies

- Teng Bian, Daniel Murphy, Rongxin Xia, Ammar Daskin, and Sabre Kais, [“Quantum computing methods for electronic states of the water molecule,” arXiv:1804.05453](https://arxiv.org/abs/1804.05453), later published in *Molecular Physics* (2019), [DOI 10.1080/00268976.2019.1580392](https://doi.org/10.1080/00268976.2019.1580392). Directly relevant: STO-3G water calculations at multiple O–H bond lengths and comparison of quantum methods, including Pairwise VQE.
- H. E. Eddins et al., [“Doubling the Size of Quantum Simulators by Entanglement Forging,” PRX Quantum 3, 010309 (2022)](https://doi.org/10.1103/PRXQuantum.3.010309). Demonstrates a water active-space calculation using entanglement forging. It is a promising resource-reduction alternative, but its setup is not the asymmetric geometry used here.

### Variational and adaptive algorithms

- Alberto Peruzzo et al., [“A variational eigenvalue solver on a photonic quantum processor,” Nature Communications 5, 4213 (2014)](https://doi.org/10.1038/ncomms5213). Foundational VQE formulation.
- Abhinav Kandala et al., [“Hardware-efficient variational quantum eigensolver for small molecules and quantum magnets,” Nature 549, 242–246 (2017)](https://doi.org/10.1038/nature23879). Supports hardware-efficient circuits as a baseline; it does not imply they outperform a chemically structured ansatz.
- Harper R. Grimsley et al., [“An adaptive variational algorithm for exact molecular simulations on a quantum computer,” Nature Communications 10, 3007 (2019)](https://doi.org/10.1038/s41467-019-10988-2). Introduces ADAPT-VQE's iterative gradient-based operator selection.
- Ho Lun Tang et al., [“Qubit-ADAPT-VQE: An Adaptive Algorithm for Constructing Hardware-Efficient Ansätze on a Quantum Processor,” PRX Quantum 2, 020310 (2021)](https://doi.org/10.1103/PRXQuantum.2.020310). Defines a qubit-operator-pool variant and analyzes pool completeness and measurement/circuit costs.
- Joonho Lee et al., [“Generalized Unitary Coupled Cluster Wavefunctions for Quantum Computation,” Journal of Chemical Theory and Computation 15, 311–324 (2019)](https://doi.org/10.1021/acs.jctc.8b01004). Introduces k-UpCCGSD, a systematically improvable paired-double plus generalized-single ansatz with a reported accuracy/cost trade-off; the paper benchmarks H₂O/STO-3G. The implementation's PUCCSD ansatz is related but is not claimed to exactly reproduce k-UpCCGSD.
- Panagiotis G. Anastasiou et al., [“TETRIS-ADAPT-VQE: An adaptive algorithm that yields shallower, denser circuit ansätze,” arXiv:2209.10562](https://arxiv.org/abs/2209.10562), published as *Physical Review Research* 6, 013254 (2024), [DOI 10.1103/PhysRevResearch.6.013254](https://doi.org/10.1103/PhysRevResearch.6.013254). Adds mutually disjoint-support operators per macrocycle; it is not an energy-based pruning paper.
- Chenfeng Cao et al., [“Mitigating algorithmic errors in quantum optimization through energy extrapolation,” arXiv:2109.08132](https://arxiv.org/abs/2109.08132), published in *Quantum Science and Technology* 8, 015004 (2022). This is the paper identified by the blueprint's arXiv number. Its method extrapolates with energy variance/algorithmic time; it does not present the claimed screen-and-prune ADAPT algorithm.

### Symmetry verification and software

- Xavier Bonet-Monroig et al., [“Low-cost error mitigation by symmetry verification,” Physical Review A 98, 062339 (2018)](https://doi.org/10.1103/PhysRevA.98.062339). Supports symmetry-based mitigation and a post-processing protocol. It does not imply universal energy stability or a predetermined fraction of rejected shots.
- Qiskit Nature 0.8 documentation: [electronic-structure ground-state solvers](https://qiskit-community.github.io/qiskit-nature/tutorials/03_ground_state_solvers.html), [UCC with VQE](https://qiskit-community.github.io/qiskit-nature/howtos/vqe_ucc.html), [ADAPT-VQE](https://qiskit-community.github.io/qiskit-nature/howtos/adapt_vqe.html), [active-space transformers](https://qiskit-community.github.io/qiskit-nature/tutorials/05_problem_transformers.html), and [symmetry-filtered exact eigensolver](https://qiskit-community.github.io/qiskit-nature/howtos/numpy_minimum_eigensolver.html).
- Qiskit Nature 0.8 [PUCCSD API](https://qiskit-community.github.io/qiskit-nature/stubs/qiskit_nature.second_q.circuit.library.PUCCSD.html) specifies paired spin-adapted excitations and particle/spin preservation.
- Qiskit Algorithms 0.4 documentation: [VQE](https://qiskit-community.github.io/qiskit-algorithms/stubs/qiskit_algorithms.VQE.html), [AdaptVQE](https://qiskit-community.github.io/qiskit-algorithms/stubs/qiskit_algorithms.AdaptVQE.html), and [AdaptVQEResult](https://qiskit-community.github.io/qiskit-algorithms/stubs/qiskit_algorithms.AdaptVQEResult.html).
- Qiskit Algorithms [ReverseEstimatorGradient API](https://qiskit-community.github.io/qiskit-algorithms/stubs/qiskit_algorithms.gradients.ReverseEstimatorGradient.html): describes reverse-mode statevector differentiation. Its cost model is classical statevector propagation, so these gradients are not a hardware shot-cost estimate.
- PySCF [SCF stability guide](https://pyscf.org/user/scf.html) and [stability API](https://pyscf.org/pyscf_api_docs/pyscf.scf.html): a converged SCF solution may be a saddle point; internal/external stability checks can detect whether loosening the RHF constraints lowers the energy. The code now records RHF internal and external stability at each point rather than inferring stability from SCF convergence alone.
- Qiskit Aer [noise-model guide](https://qiskit.github.io/qiskit-aer/tutorials/3_building_noise_models.html) and [noisy VQE tutorial](https://qiskit-community.github.io/qiskit-algorithms/tutorials/03_vqe_simulation_with_noise.html): authoritative implementation references for a later shot-based noisy-simulator comparison. Such a result must state the synthetic noise channel and its parameters; it cannot be called hardware performance.
- For a device-informed local simulation, Qiskit Aer documents [`AerSimulator.from_backend`](https://qiskit.github.io/qiskit-aer/stubs/qiskit_aer.AerSimulator.html) and the [device-noise tutorial](https://qiskit.github.io/qiskit-aer/tutorials/2_device_noise_simulation.html). The generated basic model uses backend-reported gate errors, T1/T2 relaxation, readout errors, basis gates, and coupling information. IBM describes backend properties as periodic characterization data usable for simulator noise models ([backend information](https://quantum.cloud.ibm.com/docs/en/guides/qpu-information)). This is a calibrated approximation, not a complete digital twin: context-dependent coherent errors, crosstalk, leakage, drift, and all scheduling effects are not guaranteed to be captured. The project stores the backend properties snapshot and calibration timestamp with each result.
- Qiskit's [`BackendEstimatorV2`](https://quantum.cloud.ibm.com/docs/en/api/qiskit/2.3/qiskit.primitives.BackendEstimatorV2) supports finite-shot expectation estimates with qubit-wise commuting Pauli grouping and reports a statistical standard deviation. The backend-noise study uses a fixed saved optimum and sets a precision target; the optimizer itself remains ideal-statevector. A noisy value below CASCI does not violate the exact variational theorem—the theorem applies to the exact expectation of a normalized trial state, while finite sampling and noisy channels alter the reported estimator.
- IBM Runtime documents [TREX measurement mitigation, gate twirling, and ZNE](https://quantum.cloud.ibm.com/docs/en/guides/estimator-noise-management), but these methods carry workload-dependent sampling/runtime overhead. The hardware study should report raw energy first and any mitigated estimate separately with its uncertainty; no one mitigation level is guaranteed to improve this particular H2O circuit.
- Q. Sun et al., [“The Python-based Simulations of Chemistry Framework (PySCF),” WIREs Computational Molecular Science 8, e1340 (2018)](https://doi.org/10.1002/wcms.1340). The official [PySCF quickstart](https://pyscf.org/quickstart.html) documents RHF, FCI, and CASCI; the official [installation guide](https://pyscf.org/user/install.html) explicitly says native Windows is unsupported and directs Windows users to WSL.

### Optimizer evidence and what transfers to this project

- Tilly et al., [“Performance comparison of optimization methods on variational quantum algorithms,” Physical Review A 107, 032407 (2023)](https://doi.org/10.1103/PhysRevA.107.032407). It studies SLSQP, COBYLA, CMA-ES, and SPSA with shot-based chemistry/material objectives and reports that optimizer rankings depend on the problem and system; tuned CMA-ES can be competitive with or outperform SPSA. This motivates a noisy matched-shot experiment, not claims about the current exact-statevector runs.
- Singh, Mishra, and Majumder, [“Benchmarking of Different Optimizers in the Variational Quantum Algorithms for Applications in Quantum Chemistry,” arXiv:2208.10285](https://arxiv.org/abs/2208.10285). This includes water and ideal/noisy simulations with UCC, but its main optimizer results are molecule-averaged and its study setup differs from this asymmetric CAS(8,6) experiment. Treat it as context, not a direct numerical target.
- Novák et al., [“Reliable Optimization Under Noise in Quantum Variational Algorithms,” arXiv:2511.08289](https://arxiv.org/abs/2511.08289). A recent preprint using H₂, H₄, and LiH with a truncated variational Hamiltonian ansatz; it highlights winner's-curse bias and population-statistic reporting, and finds adaptive population methods promising under its tested noise. It does not test this H₂O geometry or PUCCSD circuit, so its conclusions are hypotheses to test here.
- Qiskit's [SPSA API documentation](https://qiskit-community.github.io/qiskit-algorithms/stubs/qiskit_algorithms.optimizers.SPSA.html) states that calibration can consume extra objective calls, `maxiter` is not an evaluation cap, and SPSA is intended for noisy objectives. The existing exact-statevector optimizer study therefore cannot rank its usefulness under sampling noise.
- Shkolnikov et al., [“Avoiding symmetry roadblocks and minimizing the measurement overhead of adaptive variational quantum eigensolvers,” Quantum 7, 1040 (2023)](https://doi.org/10.22331/q-2023-06-12-1040). ADAPT pools need symmetry-aware construction; shallow depth by itself omits the operator-gradient measurement overhead. This is why ADAPT should be evaluated using total gradient/energy measurement work, not only ansatz CX count.

### Experimental priority from the combined evidence

1. Audit RHF stability and compare CASCI with orbital-optimized CASSCF at the stretched geometries. Any VQE/CASSCF comparison must rebuild the qubit Hamiltonian in the same orbitals.
2. Run the matched ansatz/resource study using the new `scripts/run_ansatz_resource_study.py`. Its CASCI error, IQR, chemical-accuracy count, parameter count, level-3 CX/depth, evaluation count, and wall time answer whether added expressibility is worth its circuit cost.
3. Densify the asymmetric O–H scan and compare warm starts against independent starts; report RHF stability and CASCI references at every point.
4. Only then compare noisy optimizers in a finite-shot loop with common total shot budgets and independent high-shot reevaluation. The present `noisy_energy.py` is a fixed-parameter noise stress test, not noisy VQE training.

Do not add more optimizer names, pruning thresholds, or noise filters unless the experiment records the cost and tests the resulting energy after full reoptimization. A lower parameter count or a rejected-shot fraction alone is not evidence of a better chemistry result.

## Checks and limitations

The code checks the constructed H–O–H angle and bond lengths in unit tests. Static Python compilation and both geometry tests pass on the available bundled Python runtime. At runtime the program checks RHF and full-FCI convergence, directly diagonalizes the small full STO-3G fixed-particle space, enforces the full-FCI/CASCI variational ordering, compares PySCF CASCI against an independently mapped, particle-sector-filtered Qiskit exact result, and aborts on disagreement. VQE energies are reported with optimizer fields actually exposed by the installed Qiskit wrapper, parameter counts, evaluation counts, and absolute error against the active-space reference.

The present host cannot invoke the user's WSL service (`Wsl/Service/E_ACCESSDENIED`), so a real PySCF/Qiskit chemistry run has not yet been performed here. Windows-side syntax and geometry tests pass. No numerical VQE claim should be made until the WSL run succeeds and produces the archived result files.
